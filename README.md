# Glassmorphism Login UI Concept

A sleek, minimalist login card interface featuring a frosted glass visual style layered over a scenic mountain landscape backdrop. Built purely with modern HTML5 and CSS3.

## Features

- **Glassmorphism Design:** Main card container and input fields use `backdrop-filter: blur()` combined with semi-transparent RGBA overlays and subtle outer drop shadows.
- **Dynamic Background Setup:** Styled with full-screen, fixed, non-repeating cover imagery featuring photographic scenic scenery by Esaias Tan.
- **Hover Micro-Interactions:** Smooth scaling transitions (`transform: scale(1.10)`) and background color changes when users hover over text inputs.
- **Pure CSS Centering:** Layout uses Flexbox both for vertical/horizontal page centering (`100vh`) and internal form stacking without external frameworks or JavaScript.

## Tech Stack

- **HTML5:** Semantic structure with native form input elements.
- **CSS3:** Flexbox layout, `backdrop-filter`, standard box shadows, dynamic transitions, and modern CSS color functions.
