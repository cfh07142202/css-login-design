# Glassmorphism Login UI Concept

A simple, lightweight login UI concept built with HTML5 and CSS3. Designed as a clean starter template or layout sketch to tweak and build upon for your own web projects.

## Features

* **Glass Effect:** Blurred, translucent card background and input fields using `backdrop-filter: blur(10px)`.
* **Hover Animations:** Smooth scaling transformations and color transitions on text inputs and the submit button.
* **Flexbox Layout:** Centered full-screen display built entirely with Flexbox without any JavaScript.
* **Form Structure:** Uses a native HTML `<form>` with username and password fields and a submit button, providing a foundation for adding backend authentication later.
* **Removable Footer Credit:** Includes a small, non-intrusive footer tag that can be customized or deleted.

## Files

* `index.html` - Form structure, inputs, submit button, and footer credit
* `style.css` - Glassmorphism rules, transitions, positioning, and hover states
